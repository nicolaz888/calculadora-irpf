# Cuenta Clara · Calculadora IRPF 2026

Prototipo web estático en español para una calculadora orientativa de IRPF. No requiere instalación: abre `index.html` en un navegador.

## Estado

- Landing page responsive con formulario inicial y sección reservada para publicidad.
- El formulario no muestra importes todavía. El alcance acordado es asalariados de 2026 para todo el territorio, con ambas salidas: retención de nómina y cuota anual aproximada.
- No se recopilan ni envían los datos del formulario.

## Antes de publicar

1. Definir el alcance del cálculo y documentar sus supuestos y fuentes por ejercicio/territorio.
2. Completar aviso legal, privacidad y consentimiento de cookies según las herramientas que se incorporen.
3. Revisar los requisitos vigentes del proveedor publicitario elegido y añadir sus etiquetas solo cuando el sitio y sus páginas estén listos.
4. Publicar en un hosting estático con HTTPS y un dominio propio.

La AEAT publicó un algoritmo de retenciones 2026 revisado, aplicable desde el 10 de septiembre de 2026. La retención es un pago a cuenta, no equivale al resultado definitivo de la declaración. El cálculo anual necesita un modelo independiente con parámetros por territorio. Fuente: https://sede.agenciatributaria.gob.es/Sede/Retenciones.shtml
